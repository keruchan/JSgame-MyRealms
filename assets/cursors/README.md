# King of the Conqueror's Realm cursors

Original, transparent 40×40 SVG artwork drawn for King of the Conqueror's Realm. Each action replaces the entire cursor silhouette; the icons do not add badges to an arrow.

| File | Cursor |
| --- | --- |
| default.svg | Bronze gauntlet pointing diagonally, also used over page controls |
| select.svg | Gold selection brackets and center diamond |
| move.svg | Green directional compass |
| attack.svg | Sword, with the blade tip as the hotspot |
| chop.svg | Broad gray steel lumber axe with a wooden handle |
| mine.svg | Curved steel mining pickaxe with a wooden handle |
| farm.svg | Steel farming hoe with a wooden handle |
| repair.svg | Steel repair hammer |
| build.svg | Builder's hammer and masonry |
| rally.svg | Rally banner |
| blocked.svg | Red prohibition ring |
| box.svg | Box-selection brackets |
| pan.svg | Closed bronze gauntlet |

`js/cursors.js` defines each cursor's hotspot and standard browser fallback. The default hotspot in `css/styles.css` matches the glove's fingertip. SVGs have no external dependencies. Contextual text remains a supplementary command hint. Touch controls retain their existing preview/confirmation flow; they do not display a mouse cursor.
